# SaySimple

SaySimple is a web app that turns dense text, such as academic papers, legal documents or official notices, into short, clear language, and translates the result into more than 50 languages, including regional Arabic dialects.

It was built for a Google AI hackathon in the APAC region, where it reached the finals.

**Live demo:** https://gemini-simplify.vercel.app

## Features

- One-click simplification of long or technical text
- Translation into 50+ languages, with dialect-level options for Arabic
- Built with Next.js and Google's Gemini models

## Run locally

```bash
npm install
npm run dev
```
